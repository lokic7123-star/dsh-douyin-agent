## 五、阶段 1：前端重构（核心工作量）

### 1.1 技术底座（一次到位）

- 放弃行内 style，改为 **class + 单 `<style>` 注入**（wallpaper-engine / qq-tts / dsh_douyin_tools 三方一致的模式）：`document.createElement('style')` + `data-plugin-css="dsh-douyin-agent/dy.module.css"` 防重复注入，`dataset.plugin = "dsh-douyin-browser-local"`。
- CSS 全部用 `dsw-alias-*` 原生令牌；状态色用 `--dsw-alias-state-success/warn/error-primary`；自有令牌只允许 `--dy-accent` 且带 alias 兜底。
- 组件层：`Section` / `Panel` / `Card` / `KV` / `Row` / `Note` / `Tab`（对标 dsh_douyin_tools 组件划分），全部 `h()` createElement，不引第三方库。

### 1.2 逐条修复（对应你的抱怨）

| 你的抱怨 | 修复 |
| --- | --- |
| 按钮换行、卡位 | tab 行与操作行改 `flex-wrap:wrap` + `gap:6px`；按钮定稿为胶囊（`padding:5px 12px; border-radius:999px; border:1px solid var(--dsw-alias-border-l2); background:transparent`），busy 态只加 `opacity:.6` 不改文案长度 |
| 状态行丑 | 重排为三段式（对齐样稿）：`● 运行中` 绿点 + `○ 2 自动恢复中` + `▲ 3 已转人工`，中间细分隔线，徽标等宽对齐；右端放「一键自检」入口 |
| 前端都是代码 | 「回复处理记录」details 改为结构化行列表（时间 + 事件 + 结果三列，等宽对齐）；「诊断报告」改可折叠分组卡片，原始 JSON 收进最后一组「原始数据」并默认折叠 |
| 悬停无反馈 | 全部可点元素 `:hover { background: rgba(255,255,255,0.04) }`（暗色）；亮色用 `rgba(0,0,0,0.04)`，经 `[data-ds-dark-theme]` 区分 |
| 排版整体 | 卡片统一 `border:1px solid var(--dsw-alias-border-l1); border-radius:12px; padding:10px 12px`；区块间距 `gap:10px`；区块标题 12.5px 三级灰 |

### 1.3 结构对齐样稿（docs/mockups/backlog-ui-mockup.html）

- 顶栏三段指标行（已做，保留但换胶囊样式）。
- 待答卡片：chip 状态徽标（等宽对齐）+ 一行摘要 + 一行原因 + 按钮组；详情默认折叠。
- 警示条 alertbar：有待答升级时黄底提示（`--dsw-alias-state-warn-primary` 10% 透明度底）。
- 处理历史：`<details>` 折叠，行列表。
- 窄屏：所有行 `flex-wrap:wrap`，禁止溢出；导航行保持单行自然滚动（既有实现保留）。

### 1.4 桌面端 main.jsx 同构

所有新 class 与结构同步到 `desktop/ui-api/src/main.jsx`（两入口同一套 CSS），防止再次出现「插件端改了桌面端没改」。
