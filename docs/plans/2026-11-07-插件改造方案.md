# 面板重设计 v2：预览稿 = 产品（前后端对应契约）

> 2026-11-07 v2。规则：本文件的 CSS 与 DOM 结构就是 client.js 将要注入的内容——预览用什么值，产品就用什么值，逐字一致。
> 预览地址：`docs/mockups/panel-redesign-v2.html`（合成数据）。

## 一、为什么上一版失败（教训入档）

1. 预览用显式色值，实装用 dsw-alias 令牌——DSH 浅色主题下 `bg-layer-1≈白`、`border-l1≈不可见`，卡片直接隐身。
2. 预览重画了整页，实装只给「有数据的部件」套壳，页面骨架还是旧平铺表单。
3. 只做皮，没吞功能。

v2 对策：**预览即产品**——预览文件里的 CSS 与 DOM 结构就是实装内容，令牌在预览里也用真实 DSH 浅色取值渲染，所见即所得。

## 二、前端契约（client.js 将注入的 PANEL_CSS 核心）

- 卡片：`background:var(--dsw-alias-bg-layer-1,#f7f8fa); border:1px solid var(--dsw-alias-border-l2); border-radius:12px; padding:12px 14px`（l2 边框，浅色下清晰可见）。
- 胶囊 tab：`font-size:12px; padding:4px 12px; border-radius:999px`，单行 `scrollbar-width:none`（9 个 tab 实测 ~700px，848px 容器内不溢出）。
- 状态行：`dy-statusline`（点+数值+说明+分隔线），仅在有内容时渲染。
- 主按钮沿用 DSH 原生 Button（primary/outline），不自绘。
- 页面骨架：每个栏目 = `dy-panel`（column gap 12）内 2~5 张 `dy-card`，卡片标题 13px/600 在卡内，不再用悬空 h3。

## 四、不吞清单（红线）

SMS/QR 登录、自动发布/投稿、自动点赞、轮询式回复参数群——模式不同或既有安全边界，理由见 `docs/research/dsh-douyin-tools-devour-notes.md`。

## 五、实施顺序（预览点头后）

0. **v2.3 修订（2026-11-07，用户逐条反馈）**：① 时段预设按钮按时长/逻辑排序：**全天 → 谷时段 → 晚间**（短在前改逻辑序）；② 废除「高级选项」折叠——每日观看上限/模型请求上限直接平铺在观看时段卡内；③ 许可名单 `.nm` 定宽 150px——状态胶囊（绿点/蓝点）垂直对齐一条线，不再随昵称长短歪斜；④ 卡片开关（自主观看/静默观看/公开评论/音频与密钥）一律**紧跟标题左侧**，不推到最右。v2.2 修订继续生效（时间范围 130px+CSS 三角箭头、深色中性灰阶去褐调）。
0. **v2.4 修订（2026-11-07，用户反馈：浅色下黑按钮突兀）**：① 主按钮弃用黑底——全部改主题强调色 `--dy-accent`（浅色 #2563eb 蓝、深色 #60a5fa 浅蓝，实装时优先读 DSH 品牌令牌随壁纸联动）；② 选中态 tab（主导航/记忆子 tab）同步换强调色；③ 深色主按钮文字用深底色 #0b1220 保证对比度；④ 普通胶囊按钮保持描边透明底，跟随主题文字色。**实装注意**：client.js 里主按钮用 DSH 原生 Button（variant primary）自带品牌色，无需自绘——预览里的 --dy-accent 仅用于预览还原，若原生 Button 颜色与壁纸联动则直接用原生。
1. client.js：替换 PANEL_CSS 为预览同款 + 重写页面骨架（全部栏目卡片化 + 紧凑表单行 + dy-sel 下拉组件 + 开关贴标题）。
2. client.js：新增观看足迹 tab + 前端错误环；desktop main.jsx/style.css 同构。
3. 后端：`/watched` + `/thumb` 聚合接口（复用帧缓存）；`/chat/unanswered` 透出 `nextRetryAt`/`waitingSince`；persona.autowrite 开关（默认关，带预算检查）。
4. 测试：定向套件全绿 + 新增接口测试；全量与基线对照（12 项环境失败不变）。
5. relay wrapup 收口，提交推送，装进 DSH 验收。
